# FCM Dashboard Client

The React + Vite dashboard is configured from `client/.env`. Start it with `npm run dev` from this directory. For Firebase setup, backend configuration, security notes, and end-to-end run instructions, see the [project README](../README.md).

Restart the Vite server after changing environment variables. The Web Push VAPID key and Firebase Web app settings are public client configuration; never put Firebase Admin credentials in this directory.
